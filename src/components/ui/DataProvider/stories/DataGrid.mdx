# DataGrid Component

<Description of={DataGridStories} />

Displays data from `<DataProvider>` in a flexible grid layout.
Ideal for card-based views or other non-tabular representations.

Requires a `renderItem` function prop to define how each data item is displayed.
The `renderItem` function receives the original data item for the row.
