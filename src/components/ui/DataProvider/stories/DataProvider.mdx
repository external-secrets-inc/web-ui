# DataProvider Component

<Description of={DataProviderStories} />

The `DataProvider` component is the core context provider for managing and distributing table/grid state. It uses TanStack Table internally to handle data manipulation (sorting, filtering, pagination, selection) and exposes this state to its children (like `DataTable`, `DataGrid`, `DataSearch`, `DataSort`).

**Key Responsibilities:**
- Holds the primary data array (`data` prop).
- Manages column definitions (`columns` prop).
- Handles state for sorting, filtering, selection, etc.
- Provides context access to child components.
- Can optionally handle loading and empty states.

## Basic Usage

Wrap your data display components (`DataTable`, `DataGrid`) and control components (`DataSearch`, `DataSort`) with `DataProvider`. Pass the `data` and `columns` props.
