# DataSearch Component

<Description of={DataSearchStories} />

Provides a search input that filters data within the parent `<DataProvider>`.
Uses the TanStack Table global filter function.

The component is a simple input field styled with a search icon.
It automatically hooks into the DataProvider context to update the table's filtering state.
