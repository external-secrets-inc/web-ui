# DataSort Component

<Description of={DataSortStories} />

Provides a dropdown menu to select the sorting column and direction for data within the parent `<DataProvider>`.
Uses the TanStack Table sorting state.

It automatically discovers sortable columns (where `enableSorting` is not `false`) and allows the user to apply sorting.
