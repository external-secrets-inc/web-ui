# MultiSelect Component

<Description of={MultiSelectStories} />

Searchable multi-select with grouping, tri-state group toggles that respect the current filter, and badge overflow handling via a compact "+N" counter with tooltip.

## Context and Design

- Search behavior: uses CMDK’s `defaultFilter` but matches against option labels only (IDs are used strictly for identity/hover stability).
- Group toggles: each group heading renders a checkbox (checked/indeterminate/unchecked). Toggling affects only items visible under the active search.
- Overflow badges: selected values render as badges; overflow collapses into a counter badge with a tooltip listing hidden selections. Wrap stories/apps with `<TooltipProvider/>`.
- Customization: customize selected badges and option rows without breaking truncation.
- Accessibility/UX: keyboard navigation via CMDK; Tooltip semantics via Radix.

## Import

```tsx
import { MultiSelect } from '@/components/ui/MultiSelect';
```

## Filtering Model

Fuzzy matching delegates to CMDK’s `defaultFilter`, but it runs against `option.label` exclusively. Option `value` is used for identity and stable selection/hover.

## Group Tri‑State Logic

Group checkbox state is derived from the set of currently visible items in that group under the active search:

- checked: all visible group items selected
- indeterminate: some but not all visible group items selected
- unchecked: none of the visible group items selected

Toggling selects/deselects only those visible items.

## Overflow Details

In `auto` mode, a resize observer determines how many badges fit without wrapping; overflow collapses into an extra counter badge with a tooltip. Wrap with `<TooltipProvider/>`.
